Module Summary
1. Text Recognition — EasyOCR (CRAFT detector + CRNN recognizer), pretrained. 2. Object Recognition — YOLOv8n, pretrained on COCO (80 classes). 3. Digit Recognition — Custom CNN, trained from scratch on MNIST in this repo, ~99% test accuracy. 4. Text-to-Speech — pyttsx3, fully offline (Windows SAPI5).
